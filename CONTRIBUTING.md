# Contributing

1. Keep changes focused and documented.
2. Run `python3 -m py_compile pentaforge.py check_tools.py`.
3. Test command rendering without touching systems you are not authorized to assess.
4. Update the README when modules or behavior change.

Prefer read-only enumeration and safe scanners. Do not add credential attacks, persistence, exploit execution, destructive testing, or denial-of-service behavior to the default orchestration layer.

# Security Policy

PentaForge is intended for authorized penetration testing, security assessment, CTFs, and lab environments.

## Safe default

The orchestrator focuses on discovery and verification. It does not intentionally perform credential brute force, password spraying, persistence, payload delivery, exploit execution, or denial-of-service activity.

## Reporting

Please do not publish sensitive exploit details in a public issue. Contact the maintainer privately through GitHub with the affected file/module, impact, reproduction details, and suggested remediation.

## Legal notice

Only run PentaForge against assets you own or have explicit permission to assess. The operator is responsible for authorization, scope, rate limits, and applicable law.
